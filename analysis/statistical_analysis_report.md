# KBL 승패 관련 통계 분석 보고서

## 핵심 요약

- 분석 단위는 3,183경기의 승리팀–패배팀 대응쌍입니다. 팀 경기 행은 6,366개, 시즌은 12개입니다.
- 대응차이 정규성을 만족한 3개 변수는 대응표본 t-검정, 비정규적인 14개 변수는 Wilcoxon 부호순위 검정을 사용했습니다.
- 두 팀 값이 경기마다 동일해 대응차이가 없는 변수는 1개이며, p=1과 효과크기 0으로 기록했습니다.
- Benjamini-Hochberg FDR 5% 기준으로 16개 변수가 승패 집단에서 유의한 차이를 보였습니다.
- 효과크기 순위는 검정 종류가 달라도 비교할 수 있도록 모든 변수에 공통으로 계산한 matched-pairs rank-biserial correlation을 사용했습니다.
- VIF 반복 진단 후 14개 변수가 남았고, 이 변수들로 PCA를 수행했습니다.
- 누적 설명력 80%에 필요한 주성분은 9개입니다.

## 다중공선성 및 PCA

- VIF 10 이상을 반복 진단했을 때 제거 후보가 된 변수: TOV%, 공격 효율, eFG%, 공격리바운드(40분)
- VIF는 변수 간 중복을 보여주는 진단값입니다. 농구적 의미가 중요한 변수는 자동 삭제하지 말고 모델 교차검증으로 최종 선택해야 합니다.
- PC1 주요 적재량: 득점(40분)(+0.59), 어시스트(40분)(+0.50), 2점 성공률(+0.40), 3점 성공률(+0.33)
- PC2 주요 적재량: 수비 효율(+0.60), 수비리바운드(40분)(-0.53), 블록(40분)(-0.32), 턴오버(40분)(-0.26)
- 주성분의 의미는 적재량 부호와 크기를 함께 보고 해석해야 하며, 축의 부호 자체는 반대로 뒤집혀도 의미가 동일합니다.

## 분석 해석 시 주의사항

1. 이 분석은 경기 후 스탯과 승패의 연관성을 설명하며 인과관계를 증명하지 않습니다.
2. 득점과 공격·수비 효율은 경기 결과와 구조적으로 가까우므로 예측 중요도로 과대해석하면 안 됩니다.
3. 목표 경기의 실제 스탯은 사전 승패 예측 모델에 넣을 수 없습니다. 모델에는 이전 경기 이동평균만 사용해야 합니다.
4. Shapiro-Wilk는 표본이 커질수록 작은 비정규성에도 민감하므로 Q-Q plot과 효과크기를 함께 확인해야 합니다.
5. 팀별 모멘텀 그래프는 시즌마다 초기화하고 현재 경기를 포함한 최근 5경기 이동평균입니다.
